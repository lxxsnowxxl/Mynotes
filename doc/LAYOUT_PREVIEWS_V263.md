# Flujo v263 sustituido por XML editables

La versión v268 reemplaza los contenedores `ComposeView` por jerarquías de vistas
Android editables. Las instrucciones actuales están en [LAYOUTS_XML_V268.md](LAYOUTS_XML_V268.md).

Los previews Kotlin de `src/debug` se conservan para comparar los diseños con las
pantallas Compose. La aplicación continúa utilizando Compose en ejecución.
