# MyNotes v41 — Widget translations

Se revisaron todas las cadenas usadas por los widgets y sus etiquetas del selector de Android.

Idiomas comprobados:
- Español
- Inglés
- Francés
- Chino simplificado

Cambios principales:
- Se añadieron las traducciones que faltaban de `widget_note_collage` y `widget_note_collage_hint` en francés y chino simplificado.
- Se corrigió `Favorites` en francés a `Favoris` y se ajustaron textos relacionados para que no mezclen inglés/francés.
- Se verificó que todos los recursos `widget_*` usados por los providers/layouts existan en los cuatro idiomas.

No se modificó el diseño, tamaño, código de carga, adjuntos ni miniaturas de los widgets.
