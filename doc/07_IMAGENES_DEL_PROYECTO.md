# Project screenshots

These screenshots represent the current MyNotes interface and are stored locally in this documentation directory so GitHub can render them directly from the repository.

- `images/note_editor.png` — note creation/editor screen with centered note-color palette and attachment controls.
- `images/settings_color_palette.png` — Settings color-palette area.
- `images/note_options_menu.png` — per-note options menu.

The root `README.md` references these files through relative repository paths. If the documentation directory is moved or renamed, update those relative paths in `README.md` as well.
