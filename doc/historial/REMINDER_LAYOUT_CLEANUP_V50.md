# MyNotes v50 — Limpieza del layout de Recordatorios

## Cambios
- Se eliminó el icono `+` de la esquina superior derecha de la pantalla de Recordatorios.
- Se eliminó el botón `New reminder` / `Nuevo recordatorio` del estado vacío.
- Se eliminó el FAB `+` inferior de esa pantalla para evitar una tercera entrada duplicada de creación.
- El botón `Recordatorios` del menú principal `+` de MyNotes abre ahora directamente el editor de nuevo recordatorio.
- La pantalla de Recordatorios queda enfocada en consultar y editar recordatorios existentes.
- Cuando Recordatorios se abre desde una notificación, se mantiene la vista de lista.

No se modificaron adjuntos, miniaturas, previews ni el editor de dibujo.
