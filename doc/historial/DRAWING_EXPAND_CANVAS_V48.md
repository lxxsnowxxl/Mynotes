# MyNotes v48 — lienzo ampliable en la misma pantalla

Se añadió un botón en la esquina superior derecha del área de dibujo.

- Al pulsarlo, el lienzo ocupa más espacio vertical.
- El panel negro de herramientas se reduce a una barra compacta.
- La barra compacta conserva color seleccionado, deshacer, rehacer y limpiar.
- Al volver a pulsar el botón, regresan todas las herramientas.
- No se abre otra Activity, diálogo ni segunda ventana.
- Los trazos existentes se reajustan al cambiar el tamaño del lienzo para evitar recortes.
- Se añadieron descripciones traducidas en español, inglés, francés y chino.
