# Origen y diferencias respecto de doc.rar

El archivo recibido contenía **60 entradas de archivo** y documentación individual para **48 fuentes Kotlin/KTS**. La revisión contra v61 encontró **72 fuentes**, es decir, **24 fuentes sin documento individual**.

Esta carpeta v62 reemplaza la cobertura individual por documentos regenerados desde el código actual, conserva las cuatro imágenes del archivo original y actualiza índices, métricas, hashes, arquitectura, recursos, widgets y recordatorios.

No se reutilizan los hashes antiguos como si fueran actuales.
