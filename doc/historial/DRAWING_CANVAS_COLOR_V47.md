# MyNotes v47 — Color configurable del lienzo

El área de dibujo puede cambiar de color desde el panel inferior.

## Cambios
- Se añadió `Color del lienzo / Canvas color` debajo de la fila de colores de tinta.
- Incluye superficies claras, pastel, grises y oscuras.
- El color seleccionado se aplica inmediatamente al área de dibujo.
- El PNG guardado conserva el color elegido.
- El borrador ahora se almacena como borrador semántico: si cambias el color del lienzo después de borrar, las zonas borradas adoptan el nuevo fondo.
- Se añadieron traducciones para español, inglés, francés y chino simplificado.
