MyNotes

MyNotes is a notes application for Android developed primarily with Kotlin + Jetpack Compose, featuring support for attachments, link previews, extensive interface customization, thumbnail caching, performance profiles, audio, backup/restore, and compatibility starting from Android 7.0.

Architecture

The main project structure follows a separation of responsibilities:

Compose UI
   ↓
ViewModel
   ↓
Repository
   ↓
Room / DataStore / private files / cache

"MainActivity" coordinates Compose navigation and system/interface policies. ViewModels expose state and actions. Repositories centralize persistence and data logic. Room stores notes and attachments, while DataStore preserves configurable preferences.

Data and Storage

- Notes are stored locally using Room.
- Attachments are stored in the application's private storage.
- Thumbnails are generated by "AttachmentPreviewCache" and stored in RAM/disk to reduce repeated decoding during scrolling.
- The cache can be regenerated if Android removes it due to low storage conditions.
- Link previews are handled independently to prevent them from blocking the main interface.

Performance Profiles

Maximum Performance

- Preferred display refresh rate: 60 Hz.
- Image/video previews: up to 360 px.
- Audio artwork: 256 px.
- PDF previews: 480 px.
- Prioritizes reduced CPU usage, memory consumption, and decoding workload.

Balanced

- Preferred display refresh rate: 60 Hz.
- Image/video previews: up to 720 px.
- Audio artwork: 512 px.
- PDF previews: 960 px.

Maximum Quality

- Up to 120 Hz when supported by the device.
- Images: up to 1280 px.
- Video previews: up to 1080 px.
- Audio artwork: 768 px.
- PDF previews: 1440 px.
- Uses preloading and progressive caching to reduce thumbnail pop-in during fast scrolling.

Refresh rates are requests sent to the system; Android may select a different display mode if the panel or compositor does not provide the exact requested refresh rate.

Android Integration

Relevant permissions and components:

- "INTERNET": link previews and remote resources.
- "RECORD_AUDIO": voice notes.
- "VIBRATE": haptic feedback.
- The microphone is declared as optional hardware.
- "FileProvider": secure file sharing.
- "ACTION_SEND": allows a note to be created from text shared by other applications.
- Edge-to-edge / immersive rendering.
- Compose synchronizes with VSYNC through the standard "Choreographer" pipeline.

Building the Project

1. Clone the repository:

git clone https://github.com/lxxsnowxxl/Mynotes.git

2. Open the project with Android Studio.
3. Configure the Android SDK locally. "local.properties" must not be committed to Git.
4. Sync Gradle and build the project from Android Studio or by using the project's Gradle wrapper.
